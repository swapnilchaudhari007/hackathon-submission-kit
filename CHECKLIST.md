# Pre-Submission Checklist

Run through this 24 hours before the deadline. Then again 2 hours before.

## Must-haves
- [ ] Demo video uploaded (YouTube/Vimeo, public or unlisted), under the time limit
- [ ] Video opens with the problem in the first 10 seconds
- [ ] Public repo link works in an incognito window
- [ ] README has setup steps a judge can follow in under 5 minutes
- [ ] Live demo URL / test build / test credentials provided (if required)
- [ ] All required fields on the submission form filled
- [ ] Every sponsor tool/API you used is named explicitly
- [ ] License file present (MIT is a safe default)

## Polish
- [ ] 1 hero image or GIF at the top of the README
- [ ] Architecture diagram (even a simple one)
- [ ] Spell-check the write-up
- [ ] Team members added to the submission
- [ ] Screenshots are real, not mockups

## After submitting
- [ ] Re-open the submission page logged out and check everything renders
- [ ] Share on LinkedIn / X with the project link
