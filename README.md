# Hackathon Submission Kit

> Copy-paste templates to turn a weekend build into a submission judges remember.

Made by [Swapnil Chaudhari](https://github.com/Swapnilchaudhari007) after shipping entries to Amazon, Meta, NVIDIA x Nebius and RevenueCat hackathons in 2026.

If this saves you time, **star the repo** and **follow me** for more dev kits.

## What's inside

| File | Use it for |
|------|-----------|
| [DEVPOST-TEMPLATE.md](DEVPOST-TEMPLATE.md) | The project story: inspiration, what it does, how you built it |
| [DEMO-SCRIPT.md](DEMO-SCRIPT.md) | A 3-minute demo video, second by second |
| [README-TEMPLATE.md](README-TEMPLATE.md) | A repo README a judge can run in 5 minutes |
| [CHECKLIST.md](CHECKLIST.md) | Final pre-submission checks + judging criteria map |

## How to use

1. Click **Use this template** (or fork).
2. Fill `DEVPOST-TEMPLATE.md` first; it forces you to name the problem.
3. Record using `DEMO-SCRIPT.md`.
4. Paste `README-TEMPLATE.md` into your project repo.
5. Run `CHECKLIST.md` 24h and 2h before the deadline.

## 5 rules that matter most

1. **Problem in the first 10 seconds** of the video.
2. **Show, don't slide.** Live demo beats a deck.
3. **Name every sponsor tool** you used.
4. **Map each judging criterion** to proof.
5. **Test your links logged out.**
